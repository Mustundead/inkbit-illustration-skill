# Inkbit Illustration · 墨點插畫

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

創作或修改黑白墨點插畫，以清楚輪廓、短排線、疏密點陣與留白呈現主視覺、場景和配圖。適用於 Inkbit 風格需求，不用於一般網站改版或精確介面與商標重繪。

## 安裝與使用

將完整的 `skills/inkbit-illustration` 資料夾複製到宿主的技能目錄。只安裝一份，預設簡體中文；可用繁體中文、英文、日文或韓文提出要求。

```text
使用 $inkbit-illustration，畫一張黑白墨點風格的旅行主題插畫。不要文字。
```
