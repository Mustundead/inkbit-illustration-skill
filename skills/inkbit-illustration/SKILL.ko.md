# Inkbit Illustration · 잉크 점묘 일러스트

[简体中文](SKILL.md) · [繁體中文](SKILL.zh-TW.md) · [English](SKILL.en.md) · [日本語](SKILL.ja.md) · [한국어](SKILL.ko.md)

## 언어와 범위
언어가 지정되지 않으면 중국어 간체를 기본으로 사용합니다. 명시한 언어를 우선하고, 그 외에는 사용자의 중국어 간체·번체, 영어, 일본어, 한국어에 맞춥니다. 해당 언어판만 읽으며 Skill ID는 하나로 유지합니다.

새 그림, 부분 편집, 시리즈, 프롬프트 작성, 검토를 구분합니다. 대화에 나온 주제, 용도, 크기와 참고를 이어받고 불필요한 설문이나 브랜드 작업으로 확장하지 않습니다. 참고 이미지를 화풍, 대상의 동일성, 구도, 편집 대상으로 구분하여 확인합니다. 사용자가 선택한 참고를 우선합니다.

## 화풍
순수한 검정 잉크와 흰 배경을 사용합니다. 크림색, 누런 종이, 갈색, 유색 강조를 넣지 않습니다. 명암은 검정 점묘, 형태를 따르는 짧은 해칭과 여백으로 표현하며 부드러운 회색 그라데이션이나 균일한 노이즈를 쓰지 않습니다. 투명 배경을 명시하면 따릅니다. 작은 크기에서도 읽히는 윤곽을 먼저 만들고 검정 면으로 무게를 잡은 뒤 자연스럽고 약간 마른 선을 더합니다. 고양이, 사다리, 산은 필수 소재가 아닙니다.

## 실행
새 프롬프트에는 대상, 동작, 구도, 잉크 처리, 배경, 용도를 담습니다. 부분 편집은 변경 사항과 고정 조건을 구분하고 비율, 무늬, 시점, 주변을 유지합니다. 이미지 편집을 사용하며 동일성이 흐트러지면 최근의 적절한 원본으로 돌아갑니다. 시리즈는 선 굵기, 점 크기, 색상, 대상 비중과 시점을 공유합니다.

실제로 제공되는 이미지 도구와 해당 참조·출력 규칙을 사용합니다. 모델 버전이나 매개변수를 지어내거나 유료 서비스 사용을 임의 승인하지 않습니다. 도구가 없으면 아직 생성하지 않았다고 표시한 프롬프트를 제공합니다. 검토나 프롬프트만 요청하면 이미지를 생성하지 않습니다.

## 확인과 전달
실제 이미지를 예정된 표시 크기로 보고 대상, 동작, 동일성, 접촉, 가림, 질감과 흑백을 확인합니다. 관찰된 결함을 집중 수정하며 같은 문제를 두 번 시도해도 진전이 없으면 후보와 남은 차이를 알리고 멈춥니다. 버전과 원본을 보존하고 이미지, 실제 저장 경로, 프롬프트 기록과 미충족 사항을 전달합니다. 생성, 통합, 검증, 사용자 수락을 구분합니다.

허용된 경우에만 프로젝트에 통합하고 실제 화면을 확인합니다. 정확한 UI, 공식 아이콘과 읽을 수 있는 글자는 원본 자료나 일반 조판을 사용합니다. 다크 모드에서 무늬와 브랜드 색을 무조건 반전하지 않습니다.
