# Prompt recipes

These are editable recipes, not API parameters. Include only fields relevant to the brief. A model or tool name is chosen from the host's actual capabilities, never from a template.

## New illustration

```text
Deliverable: [destination, aspect ratio, display size].
Subject and action: [one clear subject, action, gaze, supporting objects].
Composition: [camera, focal area, negative space, crop requirements].
Style: monochrome dry ink contours, solid black masses, form-following short hatching,
variable-density stippling, clean highlights. Texture supports the silhouette.
Background: [warm paper / supplied color / genuine alpha transparency].
Color: [monochrome / supplied accent and where it may appear].
Preserve/avoid: [only requirements relevant to this request].
```

Example: “Create a 3:2 editorial illustration of a small sailboat crossing a quiet lake. Keep the right third clear for a heading. Dry black ink, sparse water marks, denser short hatching in the boat, a distant low shoreline. Warm paper, no lettering or decorative frame.” The scene and ratio are examples, not defaults.

## Reference-based edit

```text
Image 1 is the edit target. Image 2, if provided, supplies [identity / style / composition].
Change only: [specific pose, object, or region].
Keep: [distinctive proportions, markings, materials, camera, surroundings].
Physical relationships: [needed support, contact, overlap, direction].
Match the existing ink marks, dot density, paper, scale, and edges.
Do not redesign unaffected parts. Preserve the source; save a new candidate.
```

## Transparent spot art

“One [subject] in black ink and stipple, readable at [size]. Genuinely transparent background, no paper, scenery, halo, checkerboard, or floor patch. Preserve opaque white areas that belong to the subject. Simplify fine interior marks for this display size.” Verify alpha if the host supports inspecting it; otherwise state that alpha is unverified.

## Series

Write a shared block containing palette, background, line weight, dot scale, camera, and margins. Add one short subject/action block per asset. Track filename and brief for each. A combined contact sheet can help comparison when useful; it does not replace individual files.

## Revision language

Prefer “change the handle angle; keep cup shape and texture” over “make it better.” Pair a visible defect with one bounded change. Do not add a cumulative list of every previous rejected idea.
