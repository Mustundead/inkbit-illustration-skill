# 提示词模板

以下是可调整的提示词，不是 API 参数。只保留本次需求相关字段。模型和工具必须来自当前环境的实际能力，不由模板指定。

## 新插画

```text
交付物：[用途、宽高比、展示尺寸]。
主题与动作：[明确主体、动作、视线、必要物件]。
构图：[镜头、焦点、留白、裁切要求]。
画风：单色干墨轮廓、黑色块面、顺形体的短排线、疏密变化的点阵、干净高光。
纹理服务于主体轮廓。
背景：[暖白纸面 / 指定颜色 / 真实透明通道]。
配色：[单色 / 指定强调色及使用位置]。
保留与避免：[仅列本次相关要求]。
```

示例：“创作 3:2 编辑插画：一艘小帆船驶过安静的湖面。右侧三分之一留给标题。干涩黑墨线，稀疏水面笔触，船体使用更密短排线，远处是低矮岸线。暖白纸面，不加文字或装饰边框。”场景和比例仅为示例，不是默认设置。

## 基于参考的局部修改

```text
图 1 是编辑目标。若提供图 2，它提供[角色 / 风格 / 构图]参考。
只改变：[具体动作、物件或区域]。
保持：[显著比例、色斑、材质、镜头、周围场景]。
物理关系：[必要支撑、接触、遮挡、方向]。
匹配原来的墨线、点阵密度、纸面、尺度与边缘。
不重设计未涉及部分。保留原图，另存候选。
```

## 透明点缀插画

“单个[主体]，黑墨与点阵，在[尺寸]下仍可辨认。真实透明背景，不加纸面、风景、光晕、棋盘格或地面色块。保留属于主体的实色白色区域。针对展示大小简化内部细线。”环境支持时检查 alpha，否则明确说明透明通道尚未验证。

## 系列素材

共享提示段固定色板、背景、线条粗细、点阵大小、镜头与边距。每个素材另附简短主题和动作，记录对应文件名。需要比较时可做总览图，但它不能替代独立文件。

## 修改表达

用“调整把手角度，保留杯形和纹理”代替“再好看一点”。把可见问题对应到具体修改，不累计塞入所有曾被否定的方向。
