# 风格指南

## 画法

以“小幅墨线画印刷在纸上”为出发点。清楚的轮廓与少量深色块面承担结构，短排线顺着物体表面，疏密点阵提供中间明度。主体内部保留干净的纸白高光。除非用户要求混合风格，否则避免光滑 3D 材质、喷枪阴影、像素网格或均匀做旧边缘。

包内图片仅示范墨线与点阵，不规定角色、场景、品种或视角。示例背景较密，小尺寸素材或文字附近的插画应降低密度。不要照搬任何风格参考中的解剖问题。

## 按用途调整构图

| 用途 | 调整方式 |
| --- | --- |
| 主视觉或编辑场景 | 一个明确主体；用墨色密度和尺度区分前、中、远景。为文字保留安静区域。 |
| 小型点缀插画 | 减少内部纹理，加强轮廓，简化物件；在实际大小检查，不硬塞风景细节。 |
| 透明素材 | 保留属于主体的实色高光，只移除背景；不要绘制棋盘格或纸面矩形。 |
| 系列素材 | 统一镜头高度、视觉大小、边距、轮廓粗细、点阵大小及光线方向。 |

## 角色与动作

角色身份由比例、轮廓、色斑、显著细节与材质组成。动作变化不应悄悄改变这些特征。通过支撑点、重心、关节弯曲和视线描述动作，区分承重肢体与运动中的肢体；不要求每条肢体都接触表面。检查动作实际需要的支撑。头部朝向、是否露出面部、相机视角是不同选择。

自然毛色或材质过渡依靠顺向笔触与交错色块，避免平滑渐变带。是否可爱、拟人或采用猫作为主体，由具体需求决定。

## 配色与主题

单色是默认风格语言，暖白纸面并非强制背景。需要强调色时一致使用用户提供的颜色，并保留明确指定为黑白的物件。深色页面可以保留原插画纸面，也可以单独设计深色背景。全图反相会改变角色配色，不应作为默认主题方案。
