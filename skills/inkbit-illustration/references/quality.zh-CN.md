# 视觉验收

仅检查本次交付相关项目。Skill 结构校验不等于生成插画通过视觉验收。

| 检查 | 证据或失败表现 |
| --- | --- |
| 需求 | 主体、动作、视线、镜头、数量和裁切符合请求。提示词写了“正确”不是证据。 |
| 角色保持 | 与指定原图比较轮廓、比例、色斑和显著细节。画面更精致不能补偿角色改变。 |
| 接触 | 承重部位接触指定表面，关节与遮挡合理；符合动作的运动肢体可以离地。 |
| 墨线语言 | 黑色块面可读，点阵与排线表现体积而非淹没主体。原尺寸和缩小展示都要看。 |
| 背景 | 纸面、指定颜色或 alpha 符合请求。画出的棋盘格不等于透明，主体白色细节应保留。 |
| 品牌与 UI | 提供的标志和界面事实保持准确，不把模型猜测的图标称为官方图标。 |
| 集成 | 实际使用位置加载了正确素材，没有拉伸、裁掉主体或反相角色颜色。检查受影响的主题与尺寸。 |

直接说明未满足项。原图与候选分别保存。局部修复后，复查修改区域及受影响的角色或构图。不要设置美感分数、未请求的方案数量或额外强制审批。

为复现记录需求、参考图角色、最终提示词、已知工具或模型（未知则说明）、文件、生成或修改日期、展示环境、可见问题和状态。公开示例记录不包含私人路径或用户数据。
