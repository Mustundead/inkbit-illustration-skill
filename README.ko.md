# MU LABS Inkbit Illustration · 잉크 점묘 일러스트

## 설치와 사용

`skills/inkbit-illustration` 폴더 전체를 호스트의 스킬 위치에 복사합니다. 하나만 설치하세요. 기본 언어는 중국어 간체이며 번체, 영어, 일본어, 한국어로도 요청할 수 있습니다.

```text
$inkbit-illustration을 사용해 여행 주제의 흑백 점묘 일러스트를 그려 주세요. 글자는 넣지 마세요.
```
